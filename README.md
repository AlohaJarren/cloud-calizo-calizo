# Cloud Computing - CS 530

This repository holds my cloud computing coursework at Portland State University. I started with a Flask and SQLite app, containerized it with Docker, and later deployed a version backed by Cloud Datastore to Google Cloud Run. The assignments helped me understand what it takes to move an application beyond my local machine.

For the final project, I built a Python stock research client and FastAPI server with MCP-style tool endpoints. The app brings together SEC financial data from BigQuery, price history from Alpha Vantage, and news from NewsData.io to calculate technical indicators, sentiment summaries, and a basic risk score. I also added an optional LLM summary to help explain the results.
